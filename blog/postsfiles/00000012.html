莫比乌斯反演与杜教筛

2026-11-21 · 编号 00000012

数论题的计数对象常带一个 gcd 条件。把 gcd 拆成约束再求和，往往能化成"枚举约数 + 数论分块"，那是莫比乌斯反演；当 $n$ 大到 $10^{10}$ 时，连线性筛都做不了，就要用杜教筛把前缀和算出来。

一、狄利克雷卷积

对两个数论函数定义

$$(f*g)(n)=\sum_{d\mid n}f(d)\,g\!\left(\frac{n}{d}\right)$$

它满足交换律与结合律，单位元是 $\varepsilon(n)=[n=1]$。几个常用的恒等式：

$$(\mu*1)(n)=\varepsilon(n),\qquad (\varphi*1)(n)=n,\qquad (\mu*\mathrm{id})(n)=\varphi(n)$$

其中 $1(n)=1$、$\mathrm{id}(n)=n$。莫比乌斯函数 $\mu$ 就是 $1$ 在卷积意义下的逆，因此第一条恒等式等价于 $\sum_{d\mid n}\mu(d)=[n=1]$。

二、反演的两种形式

若 $g(n)=\sum_{d\mid n}f(d)$，则

$$f(n)=\sum_{d\mid n}\mu\!\left(\frac{n}{d}\right)g(d)$$

写成卷积就是 $g=f*1\Rightarrow f=g*\mu$。另一种形式的条件是 $g(n)=\sum_{n\mid d}f(d)$（对倍数求和），此时 $f(n)=\sum_{n\mid d}\mu\!\left(\frac{d}{n}\right)g(d)$。做题时先看清求和方向是"约数"还是"倍数"，两者不能混用。

最常见的用法是处理 $[\gcd(i,j)=1]$：

$$[\gcd(i,j)=1]=\sum_{d\mid \gcd(i,j)}\mu(d)$$

于是

$$\sum_{i\le n}\sum_{j\le m}[\gcd(i,j)=1]=\sum_{d\le \min(n,m)}\mu(d)\left\lfloor\frac{n}{d}\right\rfloor\left\lfloor\frac{m}{d}\right\rfloor$$

右侧只需枚举 $d$ 并做数论分块，$O(\sqrt n)$ 一轮；若多组询问且 $n$ 不大，预处理 $\mu$ 的前缀和即可 $O(\sqrt n)$ 回答每组。

三、线性筛

$\mu$ 的取值只有 $-1,0,1$：质数为 $-1$，含平方因子为 $0$，其余按质因子个数取符号。$\varphi$ 可一并筛出。

int pri[MAXN], pcnt;
bool vis[MAXN];
int mu[MAXN], phi[MAXN];

void sieve(int n) {
    mu[1] = 1; phi[1] = 1;
    for (int i = 2; i <= n; ++i) {
        if (!vis[i]) {
            pri[++pcnt] = i;
            mu[i] = -1;
            phi[i] = i - 1;
        }
        for (int j = 1; j <= pcnt && i * pri[j] <= n; ++j) {
            int x = i * pri[j];
            vis[x] = true;
            if (i % pri[j] == 0) {
                mu[x] = 0;
                phi[x] = phi[i] * pri[j];
                break;
            }
            mu[x] = -mu[i];
            phi[x] = phi[i] * (pri[j] - 1);
        }
    }
    for (int i = 1; i <= n; ++i) mu[i] += mu[i - 1];   // 前缀和
}

mu 的前缀和会出现负数与零，做容斥时不要想当然地当成长度。筛法的循环里 i * pri[j] 用 int 时，$n$ 接近 $10^9$ 会溢出，改 long long 或先判 i > n / pri[j]。

四、杜教筛

求 $S(n)=\sum_{i\le n}f(i)$，$n$ 到 $10^{10}$，无法线性筛。取一个容易求前缀和的 $g$，令 $h=f*g$，则

$$\sum_{i\le n}h(i)=\sum_{d\le n}g(d)\,S\!\left(\left\lfloor\frac{n}{d}\right\rfloor\right)$$

把 $d=1$ 的那一项单独拿出来，得到递推

$$S(n)=\sum_{i\le n}h(i)-\sum_{d=2}^{n}g(d)\,S\!\left(\left\lfloor\frac{n}{d}\right\rfloor\right)$$

右侧的 $S(\lfloor n/d\rfloor)$ 只有 $O(\sqrt n)$ 种不同取值，按数论分块整段处理，配合记忆化，复杂度约为 $O(n^{3/4})$；预先线性筛出前 $n^{2/3}$ 项，可降到 $O(n^{2/3})$。

以 $\varphi$ 为例，取 $g=1$、$h=\mathrm{id}$，于是 $\sum_{i\le n}h(i)=\dfrac{n(n+1)}{2}$，$g(d)=1$ 让整段系数就是区间长度：

std::unordered_map<long long, long long> memo;

long long sumPhi(long long n) {
    if (n < MAXN) return phiPref[n];
    auto it = memo.find(n);
    if (it != memo.end()) return it->second;

    long long res = n * (n + 1) / 2;          // sum of id
    for (long long l = 2, r; l <= n; l = r + 1) {
        r = n / (n / l);                      // 同一段内 n/l 相同
        res -= (r - l + 1) * sumPhi(n / l);   // g(d)=1
    }
    return memo[n] = res;
}

分块边界 r = n / (n / l) 是数论分块的核心式子，写成 r = l + 1 就退化成线性。$n$ 很大时 n * (n + 1) / 2 要用 __int128 或先除后乘，$10^{10}$ 量级已经超出 64 位有符号数的安全乘法范围。

五、常见组合

  • $\sum_{i\le n}\sum_{j\le m}\gcd(i,j)$：用 $(\varphi*1)=\mathrm{id}$ 把 $d$ 提出来，化为 $\sum_d \varphi(d)\lfloor n/d\rfloor\lfloor m/d\rfloor$ 之外的变形，或用 $\mathrm{id}=\varphi*1$ 反演。
  • $\sum_{i\le n}\sum_{j\le m}[gcd(i,j)=k]$：把 $n,m$ 除以 $k$，回到互素情形。
  • 多组询问、$n\le 10^7$：预处理 $\mu$ 与 $\varphi$ 的前缀和，每组 $O(\sqrt n)$。
  • $n\le 10^{10}$：杜教筛；若同时要 $\mu$ 与 $\varphi$，两者可以共用同一个记忆化表结构，但键值要分开。

六、易错点

一是把 $[\gcd=1]$ 的展开方向搞反，得到 $\sum_{d\mid i,d\mid j}$ 却按 $\sum_{d\le n}$ 去分块。二是分块时边界取错，漏掉最后一个小区间。三是杜教筛的递归没有记忆化，复杂度直接爆掉；记忆化用 unordered_map 时，$n$ 的种类数是 $O(\sqrt n)$，规模可控，不必手写散列。四是模意义下做减法忘记取正，$\mu$ 前缀和为负时尤其容易。

验证方式：小范围与暴力对拍（枚举 $i,j$ 直接算 $\gcd$），杜教筛与线性筛的前缀和逐项对比到 $10^6$。两个都过了，再上大范围。
