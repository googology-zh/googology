动态规划专题：CDQ 分治与原地 1D/1D

2026-11-21 · 编号 0000000f

第二篇讲的分治优化，前提是"上一层已经整层算完"。当转移在同一条数组里原地进行、$f_i$ 依赖 $f_j\ (j<i)$ 时，算 $mid$ 之前左半段还没有值，普通分治就失效了。解决方式是调换递归与转移的次序，也就是 CDQ 分治。

一、问题与失败的原因

形式仍是

$$f_i=\min_{0\le j<i}\left(f_j+w(j,i)\right)$$

$w$ 满足四边形不等式，$opt_i$ 单调不减，$f_0=0$。若照搬第二篇的写法，进入函数就先算 $f_{mid}$，此时 $f_l,\dots,f_{mid-1}$ 全是初值，算出来的是错的，而且这个错误会随着递归传播下去。

正确的做法是把"算左半"提前：先递归左半，让 $f_{l..mid}$ 全部定型，再用这一段去更新右半，最后递归右半。这样每对 $(j,i)$ 恰好在"两者第一次被分到不同半边"的那个节点上被检查一次，不重不漏。

二、分治转移

在节点 $[l,r]$ 上，左半 $[l,mid]$ 已定型，右半 $[mid+1,r]$ 的候选决策点只可能来自 $[l,mid]$；来自更小下标的贡献已经由祖先节点算过，存在 $f_i$ 里。由于 $opt$ 单调，右半的决策点也随 $i$ 单调，用一个不回退的指针扫描即可，单个节点的代价与区间长度成正比。

const long long INF = (long long)4e18;
long long f[MAXN];

void solve(int l, int r) {
    if (l == r) return;
    int mid = (l + r) >> 1;
    solve(l, mid);                       // 先让左半定型
    int p = l;
    for (int i = mid + 1; i <= r; ++i) {
        while (p < mid && f[p + 1] + w(p + 1, i) <= f[p] + w(p, i)) ++p;
        f[i] = std::min(f[i], f[p] + w(p, i));
    }
    solve(mid + 1, r);
}

// 调用：f[0] = 0，其余为 INF，solve(0, n)

复杂度：每一层的区间长度之和是 $O(n)$，层数 $O(\log n)$，$w$ 的求值次数 $O(n\log n)$。这个界依赖两个条件：$w$ 必须 $O(1)$ 可算；指针的范围必须限制在 $[l,mid]$。写成全区间扫描，单节点代价回到 $O(n)$，总复杂度退化成 $O(n^2)$，与暴力没有区别。

等号的取舍要固定。上面的 <= 让指针尽量右移，等价于"值相同时取较大的决策点"。若要求取较小决策点，改成 <，两种写法各自都能保持单调，混用则可能在同一层内来回移动。

三、正确性补一句

归纳来看：节点 $[l,r]$ 进入时，$f_{l..r}$ 已包含所有 $j<l$ 的转移（由祖先完成）；递归左半后，$f_{l..mid}$ 又补上了 $[l,mid-1]$ 内部的转移，于是它完整；随后右半只缺 $[l,mid]$ 这些决策点，扫描把它们补上；最后递归右半，重复同样的论证。递归到叶子时，$f_i$ 已经收到全部 $j<i$ 的贡献。

这套论证同时说明了为什么"先递归、后转移"不能随便交换：交换之后就变成第二篇的按层形式，只适合 $f$ 依赖另一条数组的情形。

四、与在线决策单调的关系

同一问题还有另一种做法：从左到右依次确定 $f_i$，同时维护每个决策点"成为最优"的阶段区间，新决策点用二分找出它取代旧决策点的位置。每次操作 $O(\log n)$，总 $O(n\log n)$，空间 $O(n)$。它适合一维情形，但状态换成二维、转移来源不止一条数组时，写起来比 CDQ 麻烦得多。

CDQ 的代价是常数：每个节点都要重新从 $l$ 起指针，虽然均摊线性，实际运行比单调队列慢数倍。$n\le 10^6$ 时这个常数值得在意，能用单调队列的场合不要用 CDQ。

五、适用面与坑

  • 转移代价 $w(j,i)$ 需要 $O(1)$ 求值。若它依赖莫队式的区间增删，$w$ 的单次代价乘进 $O(n\log n)$，通常就不划算了。
  • $f$ 的初值只能是基底（$f_0$）与正无穷，其余要靠递归补齐；若提前给某些 $f_i$ 赋了估计值，扫描时会把这些值当成合法决策，结果偏小且难以察觉。
  • 二维情形：$f_{i,j}$ 依赖 $f_{i',j'}$ 且 $i'<i$ 时，把第一维做 CDQ、第二维在节点内做一遍转移，复杂度多一个 $O(\log)$ 或 $O(n)$ 的因子，要按数据范围重新估。
  • 取模的最优值问题不要用这套做法：单调性建立在实数序上，取模之后序被破坏，决策单调不再成立。

验证办法仍是老一套：写一份 $O(n^2)$ 的暴力，随机小数据对拍；再检查 $opt$ 是否单调。CDQ 的代码短，出错几乎都在指针边界与等号方向上，对拍几组就能定位。
