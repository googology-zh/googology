多项式乘法：NTT 的推导与实现

2026-11-17 · 编号 0000000a

两个次数为 $n$ 的多项式直接相乘是 $O(n^2)$；换成点值表示，乘法变成逐点相乘，只有 $O(n)$。所以只要能快速地来回转换系数与点值，卷积就能在 $O(n\log n)$ 内完成。快速傅里叶变换做的是这件事，数论变换（NTT）是它在模意义下的版本，没有浮点误差。

一、单位根与原根

取 $n=2^k$，在模 $p$ 意义下取 $n$ 次单位根 $\omega_n=g^{(p-1)/n}$，其中 $g$ 是模 $p$ 的原根。要让它存在，$p-1$ 必须能被 $n$ 整除，因此模数取形如 $c\cdot2^k+1$ 的素数。常用的三个：

  • $998244353=119\cdot2^{23}+1$，原根 $3$，支持长度到 $2^{23}$。
  • $1004535809=479\cdot2^{21}+1$，原根 $3$。
  • $469762049=7\cdot2^{26}+1$，原根 $3$。

原根的含义是 $g^1,g^2,\dots,g^{p-1}$ 遍历 $1$ 到 $p-1$ 的所有非零剩余，所以 $\omega_n$ 的阶恰为 $n$。逆变换用 $\omega_n^{-1}=\omega_n^{n-1}$，最后整体乘 $n^{-1}$。

二、蝶形

Cooley–Tukey 把长度为 $n$ 的变换拆成偶下标与奇下标两个长度 $n/2$ 的变换 $A_0,A_1$，合并式为

$$A(\omega_n^t)=A_0(\omega_{n/2}^t)+\omega_n^tA_1(\omega_{n/2}^t)$$ $$A(\omega_n^{t+n/2})=A_0(\omega_{n/2}^t)-\omega_n^tA_1(\omega_{n/2}^t)$$

其中 $0\le t<n/2$。这来自 $\omega_n^{n/2}=-1$ 与 $\omega_n^{2t}=\omega_{n/2}^{t}$。递归实现是 $O(n\log n)$，但函数调用与内存分配的开销很大。迭代版先做位逆序置换，把递归的访问次序摊平，再自底向上逐层合并，内层访问连续，缓存友好。

三、实现

const int MOD = 998244353, G = 3;

int power(int a, int b) {
    int r = 1;
    for (; b; b >>= 1, a = (long long)a * a % MOD)
        if (b & 1) r = (long long)r * a % MOD;
    return r;
}

void ntt(std::vector<int> &a, bool inv) {
    int n = a.size();
    for (int i = 1, j = 0; i < n; ++i) {
        int bit = n >> 1;
        for (; j & bit; bit >>= 1) j ^= bit;
        j ^= bit;
        if (i < j) std::swap(a[i], a[j]);
    }
    for (int len = 2; len <= n; len <<= 1) {
        int w = power(G, (MOD - 1) / len);
        if (inv) w = power(w, MOD - 2);
        for (int i = 0; i < n; i += len) {
            int cur = 1;
            for (int k = 0; k < len / 2; ++k) {
                int u = a[i + k];
                int v = (long long)a[i + k + len / 2] * cur % MOD;
                a[i + k] = u + v >= MOD ? u + v - MOD : u + v;
                a[i + k + len / 2] = u - v < 0 ? u - v + MOD : u - v;
                cur = (long long)cur * w % MOD;
            }
        }
    }
    if (inv) {
        int ni = power(n, MOD - 2);
        for (int &x : a) x = (long long)x * ni % MOD;
    }
}

位逆序置换里 j 始终保持 i 的位反转，bit 从最高位往下试，这段写法比"逐位拼出反转值"快很多。

卷积的流程：长度取不小于 $n+m-1$ 的二的幂，两个数组补零，各做一次正变换，逐点相乘，做一次逆变换。

std::vector<int> convolution(std::vector<int> a, std::vector<int> b) {
    int need = a.size() + b.size() - 1, n = 1;
    while (n < need) n <<= 1;
    a.resize(n); b.resize(n);
    ntt(a, false); ntt(b, false);
    for (int i = 0; i < n; ++i) a[i] = (long long)a[i] * b[i] % MOD;
    ntt(a, true);
    a.resize(need);
    return a;
}

四、常数

  • int 乘法必须转 long long，$998244353^2\approx10^{18}$，不转就溢出。
  • 加减改成条件判断，省掉两次取模；上面的写法依赖 $u,v\in[0,MOD)$ 这个前提。
  • 每层重新调用快速幂求单位根的开销不可忽略，可以把每层的根预计算成表，或干脆预计算全长度的根数组按下标取值。
  • 长度固定的多次卷积，把 rev 数组只算一次，省掉每次的位逆序循环。
  • 递归版在 $n=2^{20}$ 附近比迭代版慢数倍，除非为了可读性，不要用。

五、任意模数

题目给的模数不一定是 NTT 友好的。三条路，按实现难度从高到低排：

三模 CRT：取三个 NTT 模数分别卷积，再用中国剩余定理合并。系数真值小于三者乘积（约 $4.7\times10^{26}$）时结果唯一。合并过程要用 __int128 或逐级取模，直接乘会溢出。

拆位：把系数拆成高 15 位与低 15 位，两个多项式各拆两份，做三次或四次卷积再拼回去。位数按模数大小选，拆得太细会多做好几次变换。

long double FFT：靠 80 位精度把误差压到可接受范围，实现最简单，但对拍必须做；系数上 $10^9$、长度上 $10^6$ 时误差会累积，不能想当然。

六、还能接着推什么

有了卷积，一串经典算法就有了基础：多项式求逆（牛顿迭代，$O(n\log n)$）、多项式除法与取模、多项式 exp 与 log、分治卷积（CDQ 分治配 NTT）、带通配符的字符串匹配。它们的共同点是把一个非线性问题化成若干次乘法，难点从"怎么乘"转到了"怎么把式子整理成能乘的形式"。

练手顺序建议：先写裸卷积并和 $O(n^2)$ 对拍，再写多项式求逆，最后做一次分治卷积。每次都用随机数据和暴力比对，NTT 的常数与边界问题（长度不足、模数选错、逆变换忘乘 $n^{-1}$）在随机数据上很快就会暴露。
