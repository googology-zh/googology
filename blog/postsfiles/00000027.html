TypeScript 入门：类型、泛型与收窄

2026-11-21 · 编号 00000027

TypeScript 是带静态类型的 JavaScript：写出来的类型只在编译期起作用，编译后全部擦除，运行时仍然是普通 JS。入门部分先解决配置，再依次讲基础类型、接口与别名、泛型、联合收窄、类。

一、安装与配置

npx tsc --init
npx tsc --noEmit

// tsconfig.json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "strict": true,
    "outDir": "dist"
  }
}

tsc 既能编译也能只做类型检查，--noEmit 就是只检查不产出文件。strict 一次打开 noImplicitAny、strictNullChecks、strictFunctionTypes 等一组检查，新项目应当直接开。

运行时不认识类型，所以不能写 if (x instanceof MyInterface)。要在运行时判断形状，只能检查真实存在的值：typeof、instanceof、in、字面量比较。

二、基础类型

let n: number = 1;
let s: string = "x";
let arr: number[] = [1, 2];
let tuple: [string, number] = ["a", 1];
let u: unknown = JSON.parse(text);

function fail(): never {
  throw new Error("unreachable");
}

any 关闭检查并且会向调用方扩散，尽量不用；unknown 是安全的顶层类型，必须收窄后才能访问属性；never 表示函数不可能返回，可用于完整性检查；void 表示返回值被忽略。

number 只有一种数字类型，整数与浮点不分（bigint 是另一回事）。tuple 的长度与每个位置的类型都固定，越界访问在开启 noUncheckedIndexedAccess 后才有 undefined 提醒。

三、接口与类型别名

interface User {
  id: number;
  name?: string;
  readonly tags: string[];
}

type Point = { x: number; y: number };
type Id = string | number;

interface 可以声明合并，适合描述对象形状与给第三方库补类型；type 可以做联合、交叉、条件类型，表达力更强。两者在多数场景可以互换，团队内定一条规则即可。

可选属性 name?: string 与 name: string | undefined 在 exactOptionalPropertyTypes 下不等价：前者不允许显式赋 undefined。索引签名 [key: string]: number 会约束所有字符串键，包括不想要的。

四、函数与泛型

function first<T>(arr: T[]): T | undefined {
  return arr[0];
}

const pick = <T, K extends keyof T>(obj: T, key: K): T[K] => obj[key];

泛型在调用处推断，推断不出来才需要显式写 first<string>(["a"])。extends 约束类型参数必须满足某个形状，keyof T 取出键的联合，T[K] 取出对应的值类型。

在 .tsx 文件里，箭头函数的泛型要写成 <T,>，否则解析器会把它当成 JSX 标签的开头。函数重载写多条签名加一条实现签名，实现签名对外不可见。

五、联合类型与收窄

type Shape =
  | { kind: "circle"; r: number }
  | { kind: "rect"; w: number; h: number };

function area(s: Shape): number {
  switch (s.kind) {
    case "circle": return Math.PI * s.r ** 2;
    case "rect": return s.w * s.h;
  }
}

typeof、instanceof、in、字面量判别都能触发收窄。给联合的每一支加一个共同的字段（这里是 kind），是最容易维护的做法；switch 的每个分支处理完，编译器就能推出剩余分支。

收窄只在当前作用域有效。把窄化后的变量传进回调，回调里它又退回联合类型，因为编译器无法保证回调执行时值没变。需要保住类型就把值复制到新的局部变量。

六、类与修饰符

class Box {
  constructor(private readonly value: number) {}
  get(): number { return this.value; }
}

abstract class Base {
  abstract run(): void;
}

参数属性 private readonly value: number 会同时声明字段并赋值。注意 private、protected 只是编译期约束，运行时仍能从外部访问，真私有要用 #field。implements 只检查形状，不继承实现。

abstract 类不能实例化，子类必须实现抽象方法。readonly 只禁止重新赋值，不禁止修改对象内部；初始化之后仍能 push 数组。

七、易错点

  • 把类型当成运行时的检查，写了 instanceof MyInterface。
  • any 一路传下去，最后整条链路都失去检查。
  • 以为 readonly 能保护数组内容不被改。
  • 在 .tsx 里写箭头泛型不加逗号，编译报 JSX 错误。
  • 关闭了 strictNullChecks，undefined 到处漏。
  • 用 as 强行断言绕过报错，把问题挪到运行期。
