计算几何：凸包、旋转卡壳与半平面交

2026-11-21 · 编号 00000013

计算几何的算法本身都不长，难在退化情形与精度。坐标是整数时一律用叉积做判断，把除法留到最后一步；坐标是实数时，eps 要按数据量级取，而不是凭感觉写一个 $10^{-8}$。

一、叉积与转向

对向量 $a=(x_1,y_1)$、$b=(x_2,y_2)$，叉积为

$$a\times b=x_1y_2-x_2y_1$$

符号表示 $b$ 在 $a$ 的左侧还是右侧：正为左转，负为右转，零为共线。三角形 $ABC$ 的有向面积是 $(B-A)\times(C-A)$ 的一半。"点在线段哪一侧""两线段是否相交""多边形是否凸"的判据都从这一个量出发。

坐标到 $10^9$ 时，两个坐标差相乘在 $10^{18}$ 量级，恰好卡在 long long 的边缘。稳妥做法是用 __int128 算叉积、只取符号，不要让它参与后续加法。

二、凸包：Andrew 单调链

按 $x$ 再按 $y$ 排序去重，从左到右扫出下凸壳，再从右到左扫出上凸壳。每加入一个点，若最后三点构成右转或共线，就弹出中间点。剔除共线点用 cross <= 0，保留共线点用 cross < 0，两种写法对应两种输出要求，混用会让点数与题目要求不符。

struct P { long long x, y; };
P operator-(P a, P b) { return {a.x - b.x, a.y - b.y}; }
__int128 cross(P a, P b) { return (__int128)a.x * b.y - (__int128)a.y * b.x; }
__int128 cross(P o, P a, P b) { return cross(a - o, b - o); }
int sgn(__int128 v) { return v > 0 ? 1 : (v < 0 ? -1 : 0); }

std::vector<P> convexHull(std::vector<P> p) {
    std::sort(p.begin(), p.end(), [](P a, P b) {
        return a.x != b.x ? a.x < b.x : a.y < b.y;
    });
    p.erase(std::unique(p.begin(), p.end(), [](P a, P b) {
        return a.x == b.x && a.y == b.y;
    }), p.end());

    int n = p.size();
    if (n <= 2) return p;
    std::vector<P> h(2 * n);
    int k = 0;

    for (int i = 0; i < n; ++i) {                 // 下凸壳
        while (k >= 2 && sgn(cross(h[k - 2], h[k - 1], p[i])) <= 0) --k;
        h[k++] = p[i];
    }
    for (int i = n - 2, t = k + 1; i >= 0; --i) { // 上凸壳
        while (k >= t && sgn(cross(h[k - 2], h[k - 1], p[i])) <= 0) --k;
        h[k++] = p[i];
    }
    h.resize(k - 1);                              // 去掉重复的首尾
    return h;
}

t = k + 1 是上凸壳的弹出下界，它保证上凸壳不会把下凸壳的点弹掉。全部点共线时结果是两个端点；点数少于 3 时直接返回，不要进循环。凸包按逆时针给出，面积用相邻点叉积求和、取绝对值再除以二。

三、旋转卡壳：凸包的直径

直径的两个端点一定是对踵点：一条平行线卡住凸包的一侧，另一条平行线在另一侧相切。沿凸包逆时针移动第一条支撑线时，对踵点也单调移动，于是用一个只前进的指针枚举，$O(h)$。

对边 $(i,i+1)$，比较它到顶点 $j$ 与 $j+1$ 的三角形面积，哪边大就把 $j$ 往哪边挪。挪到最大后，用 $(i,j)$ 与 $(i+1,j)$ 的距离更新答案。

__int128 dist2(P a, P b) {
    P d = a - b;
    return (__int128)d.x * d.x + (__int128)d.y * d.y;
}

__int128 diameter(const std::vector<P> &h) {
    int m = h.size();
    if (m == 1) return 0;
    if (m == 2) return dist2(h[0], h[1]);
    __int128 best = 0;
    int j = 1;
    for (int i = 0; i < m; ++i) {
        P a = h[i], b = h[(i + 1) % m];
        while (cross(a, b, h[(j + 1) % m]) > cross(a, b, h[j]))
            j = (j + 1) % m;
        best = std::max(best, std::max(dist2(h[i], h[j]), dist2(h[(i + 1) % m], h[j])));
    }
    return best;
}

指针 $j$ 不重置，整轮最多转两圈，复杂度线性。m <= 2 必须单独返回，否则 h[(j+1)%m] 与 $a,b$ 重合，面积恒为 0，指针不前进也看不出错。

四、半平面交

每条约束写成有向直线 $ax+by+c\ge 0$，要求的区域是直线左侧。流程：

  1. 把每条直线化成方向向量与左法向，按极角排序。
  2. 去掉极角相同、方向相同的直线，只保留更严格的一条（平行且同向时取 $c$ 更小的）。
  3. 用双端队列依次加入直线。加入前先看队尾两条直线的交点是否在新直线右侧，是则弹出队尾；再看队首两条直线的交点是否在新直线右侧，是则弹出队首。
  4. 全部加完后，用队首直线检查队尾交点、用队尾直线检查队首交点，把不合法的端点去掉。
  5. 剩余直线围成的多边形即为答案，用相邻交点叉积求和得面积。

求交点用两直线方程联立：$x=\dfrac{b_1c_2-b_2c_1}{a_1b_2-a_2b_1}$，$y=\dfrac{c_1a_2-c_2a_1}{a_1b_2-a_2b_1}$，分母为两方向向量的叉积，为零说明平行，这种情况在排序去重阶段就应处理掉。

退化情形有三类：交集为空、交集无界（最后得到的"多边形"不闭合）、交集退化成点或线段。题目通常保证有界，但判空仍要做：队列为空、或最终点数少于 3，都应视为空。

五、易错点

  • 排序只比 $x$ 不比 $y$，同 $x$ 的点顺序不稳定，凸包会漏点。
  • 叉积用 int 或 long long 直接乘，$10^9$ 坐标下溢出成负数，转向判断全部反过来。
  • 半平面交的方向搞反，把所有约束取成右侧，得到的是补集。
  • 浮点 eps 用到整数坐标上，共线点被误判，点数不稳定。整数数据不要引入 eps。
  • 旋转卡壳的指针初值取 0 而不是 1，第一条边退化，后面单调性被破坏。

验证方式：随机点集上把凸包算法与"枚举所有点对、检查是否所有点都在同侧"的暴力对比；直径与 $O(n^2)$ 枚举所有点对对比。半平面交的验证更麻烦，可以先用矩形与三角形的交来对拍面积。
