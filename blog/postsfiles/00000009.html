最大流最小割与线性规划对偶

2026-11-16 · 编号 00000009

最大流是少数几个既有组合意义、又能在多项式时间内求解的优化问题。把它写成线性规划，对偶问题恰好是最小割，两个最优值相等这件事可以用残量网络直接构造出来。很多看起来不像网络流的题，都是这一步对偶之后的变形。

一、定义与残量网络

给定有向网络 $G=(V,E)$，每条边有容量 $c(e)$。流 $f$ 满足 $0\le f(e)\le c(e)$，并且除源点 $s$ 与汇点 $t$ 之外，每个点流入总量等于流出总量。流量定义为从 $s$ 净流出的量。

残量网络上，每条边保留 $c(e)-f(e)$ 的正向残量与 $f(e)$ 的反向残量。沿残量网络找到一条 $s\to t$ 的路径，即增广路，把路径上的最小残量加到流上，得到的新流仍然可行，流量严格增加。反过来，残量网络上不存在增广路时，流已经是最大流。这两句话合起来是 Ford–Fulkerson 方法，Dinic、ISAP 都是它的具体实现。

二、Dinic

BFS 给残量网络分层，只允许沿层数递增的边走；DFS 沿层次图推流，用当前弧跳过已经满的边。一次 BFS 之后把所有可能的增广做完，称为一个阻塞流。一般图上的复杂度上界是 $O(n^2m)$，单位容量图上是 $O(m\sqrt m)$。实际运行远快于这个上界，除非数据专门构造。

struct Edge { int to, nxt; long long cap; };
int head[MAXN], dep[MAXN], cur[MAXN], ecnt = 1;
Edge edge[MAXM << 1];

void add(int u, int v, long long c) {
    edge[++ecnt] = {v, head[u], c}; head[u] = ecnt;
    edge[++ecnt] = {u, head[v], 0}; head[v] = ecnt;
}

bool bfs(int s, int t) {
    std::memset(dep, -1, sizeof dep);
    std::queue<int> q;
    dep[s] = 0; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int i = head[u]; i; i = edge[i].nxt) {
            int v = edge[i].to;
            if (edge[i].cap > 0 && dep[v] == -1) {
                dep[v] = dep[u] + 1;
                q.push(v);
            }
        }
    }
    return dep[t] != -1;
}

long long dfs(int u, int t, long long f) {
    if (u == t) return f;
    for (int &i = cur[u]; i; i = edge[i].nxt) {
        int v = edge[i].to;
        if (edge[i].cap > 0 && dep[v] == dep[u] + 1) {
            long long d = dfs(v, t, std::min(f, edge[i].cap));
            if (d) {
                edge[i].cap -= d;
                edge[i ^ 1].cap += d;
                return d;
            }
        }
    }
    return 0;
}

long long dinic(int s, int t) {
    long long flow = 0;
    while (bfs(s, t)) {
        std::memcpy(cur, head, sizeof head);
        long long d;
        while ((d = dfs(s, t, LLONG_MAX))) flow += d;
    }
    return flow;
}

ecnt 从 1 开始，保证 i ^ 1 成对；边数组按 $2m$ 开，反向边也算一条。递归深度最大为 $n$，$n$ 上万时要改迭代，或者把栈开大。

三、最小割

割是把点集分成 $S$（含 $s$）与 $T$（含 $t$）两部分，容量为所有从 $S$ 指向 $T$ 的边的容量之和。任一可行流都不超过任一割：把流量按割的两侧拆开，

$$|f|=f(S,T)-f(T,S)\le f(S,T)\le c(S,T)$$

这是弱对偶，方向上只说明最大流不超过最小割。等号由构造给出：取最大流，在残量网络上从 $s$ 出发做可达性标记，令 $S$ 为可达点集。$s\in S$，而 $t\notin S$，否则还存在增广路。所有从 $S$ 到 $T$ 的边必然满流，所有从 $T$ 回 $S$ 的边流量必为 0，于是 $|f|=c(S,T)$。

这段证明同时给出了读最小割的方法：最大流跑完之后，残量网络上 $s$ 的可达集合就是某个最小割的 $S$ 侧。需要输出割边时，检查每条原边是否从 $S$ 指向 $T$ 且已满流即可。

四、几种常见转换

  • 最大权闭合子图：正权点连 $s$、容量为权值；负权点连 $t$、容量为权值的绝对值；原图的依赖边容量为无穷。答案是正权之和减去最小割。无穷边保证依赖关系不会被割断。
  • 二分图最小点覆盖：等于最大匹配（König 定理）。构造点覆盖时，在最大匹配的残量网络上从左侧未匹配点出发做交错路可达性，取"可达的左侧点"与"不可达的右侧点"。
  • 平面图最小割：建对偶图，把每个面缩成点，跨边的相邻面连边，容量为原边容量，再求 $s$ 到 $t$ 的最短路。网格图是最常见的情形。
  • 有源汇上下界可行流：加一条 $t\to s$、容量无穷的边化为无源汇；对每条边拆出下界，按入出度差建超级源 $S'$ 与超级汇 $T'$，跑满流后判断 $S'$ 的出边是否全部满流。求最大流时先去掉附加边，再在原图上继续增广。

五、费用流与势函数

带单位费用的最小费用最大流，常规做法是每次沿最短路增广。反向边的费用为负，图里因此存在负权边，只能用 SPFA 或 Bellman–Ford 找最短路，复杂度很依赖数据。

把势函数引进来可以去掉负权。令 $h_v$ 为上一次增广后源点到 $v$ 的最短路距离，定义约化费用

$$c'(u,v)=c(u,v)+h_u-h_v$$

由最短路的最优子结构 $h_v\le h_u+c(u,v)$，可知 $c'(u,v)\ge0$，于是此后每次增广都可以用 Dijkstra，总复杂度 $O(Fm\log n)$，$F$ 为需要增广的次数。第一次没有 $h$ 可用，若原图无负边就直接取 $h=0$，否则先跑一次 SPFA。

势函数必须在每次增广之后更新，不能只算一次；另外 $h$ 的初值要和增广方向一致，源汇写反是这类代码最常见的错误。

六、写题时的细节

  • 容量之和常常超过 32 位，流量、边容量、答案全程 long long。
  • 无向边要建两条容量均为 $c$ 的有向边，即调用两次 add；用一条边配双向残量会把残量算反，最小割的结果随之出错。
  • Dinic 的瓶颈通常在 BFS 而不是 DFS，点少边多时不要把优化精力放错地方。
  • 点数上万、边数上十万时，静态数组比 vector 更稳；多次建图要在每次之前清空 head 与 ecnt。
  • 涉及最小割方案输出时，务必在最大流结束后再做可达性标记，中途标记得到的是某个中间状态的割。
