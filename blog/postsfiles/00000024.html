Perl 进阶：引用、对象与模块

2026-11-21 · 编号 00000024

进阶部分处理的是同一批语法在规模变大之后的用法：引用与嵌套数据结构、bless 对象、文件与目录、正则的编译与命名捕获、异常处理，以及从 CPAN 取模块。

一、引用与嵌套结构

my @a = (1, 2);
my $ref = \@a;
print $ref->[0], "\n";

my %h = (list => [1, 2], name => "x");
print $h{list}[1], "\n";

use Data::Dumper;
print Dumper(\%h);

\@a 取数组引用，\%h 取哈希引用，\$x 取标量引用。解引用有 $ref->[0]、$$ref[0]、@{$ref} 三种写法，箭头在两层之间可以省略，所以 $h{list}[1] 不需要写成 $h{list}->[1]，但超过两层时建议每层都写箭头，读起来清楚。

引用比较比的是地址，$ref == $other 判断是否指向同一份数据；比较内容要用 Data::Dumper 或 Storable::freeze。深拷贝也可以用它，手写递归复制容易漏掉自引用结构。

二、bless 与对象

package Point;

sub new {
    my ($class, $x, $y) = @_;
    my $self = bless { x => $x, y => $y }, $class;
    return $self;
}

sub x {
    my $self = shift;
    return $self->{x};
}

1;

bless 把一个引用打上包名，之后用这个引用调用方法时，Perl 会到对应包里找同名子程序。方法调用的第一个参数是类名（构造时）或对象本身（实例方法时），所以 my ($self) = @_ 是固定起手式。

继承靠 @ISA 或 use parent，方法查找沿 @ISA 向上。Perl 没有访问控制，_private 这类前缀只是约定；要真正限制就在构造时用词法闭包把数据关起来，代价是调试时看不到内部状态。

三、文件与目录

open(my $fh, '<', $path) or die "open $path: $!";
while (my $line = <$fh>) {
    chomp $line;
    print $line, "\n";
}
close $fh;

open(my $out, '>', "out.txt") or die "open out.txt: $!";
print $out "done\n";
close $out;

一定要用三参数 open：两参数形式会把文件名里的 | 当成管道、把开头空格当成模式，属于注入风险。检查返回值，失败时 $! 给出系统错误原因。追加写用 >>，二进制文件加 binmode($fh)。

<> 会依次读 @ARGV 里的文件，没有参数时读标准输入；@ARGV 被脚本改过时行为会跟着变。遍历目录用 File::Find 或 Path::Tiny，手写 opendir 别忘了过滤 . 与 ..。

四、正则进阶

my $re = qr{ (\d{4}) - (\d{2}) - (\d{2}) }x;
if ("2026-11-21" =~ $re) {
    print "$1 $2 $3\n";
}

my $s = "hello world";
$s =~ s/(?<word>\w+)/uc($+{word})/ge;
print "$s\n";

qr{} 预编译正则，循环里反复使用同一个模式能省掉编译开销；/x 允许在模式里换行与写注释。命名捕获用 (?...)，结果在 %+ 里；/e 把替换部分当代码求值，能力大但也危险，拼接进来的外部字符串会变成可执行代码。

零宽断言 (?=...)、(?!...)、(?<=...)、(?<!...) 只检查位置不消耗字符，适合“后面必须跟某物”的约束。递归结构用 (?1) 引用第一组，能匹配配对括号这类嵌套文本；写之前先想清楚要不要加 (?>...) 防回溯爆炸。

五、错误处理

my $ok = eval {
    die "boom\n" if $bad;
    1;
};
if (!$ok) {
    warn "caught: $@";
}

eval 捕获 die，错误文本在 $@ 里。它很快被下一次 eval 覆盖，所以捕获后立刻存进变量。die 文本末尾带换行时不会附加文件名行号，适合面向用户的报错；不带换行则附加位置，适合开发者排查。

Try::Tiny 提供了 try/catch/finally 的写法，避免了 $@ 被覆盖的老问题；autodie 则让 open、close 这类内置函数失败时自动抛异常，少写一堆 or die。

六、常用模块

Getopt::Long 解析命令行选项，JSON::PP 编解码 JSON，Path::Tiny 读写文件与路径拼接，File::Temp 生成临时文件，Time::Piece 处理日期。这些模块都在核心发行版里，不需要额外安装。

第三方模块用 cpanm 模块名 安装，依赖写进 cpanfile。perl -M模块 -e 1 可以确认模块是否装好、能否加载。版本敏感的脚本在文件头写 use 5.036;，低于该版本会直接拒绝运行。

七、易错点

  • 两参数 open，文件名被当成模式或管道执行。
  • 引用层级写错：$h{a}{b} 与 $h{a}{b} 少写一层会得到引用而不是值。
  • bless 之后忘了 return $self，构造返回真值但不是对象。
  • eval 之后没有立即保存 $@。
  • 正则加 /g 又在标量上下文里当列表用，结果只拿到第一个。
  • sort 默认按字符串比较，数字排序要写 sort { $a <=> $b }。
