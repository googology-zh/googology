Python 入门：环境、类型与基本结构

2026-11-21 · 编号 00000021

本文按“能跑起来、能读懂、能改对”的顺序整理 Python 的入门要点：环境、类型、序列、函数、异常与文件、类与模块。示例默认 Python 3.10 及以上，涉及语法的地方只写标准库。

一、环境与运行方式

Python 2 与 3 的分歧已经是历史问题，现在只认 3.x。解释器装进 PATH 之后，脚本用 python 文件名 运行，也可以用 python -m 模块名 以模块方式运行——后者会走当前的解释器路径，在虚拟环境里更可靠。

python -m venv .venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate      # Linux / macOS
python -V
pip install requests
python -m http.server 8000     # 起一个本地静态服务

虚拟环境的作用是把依赖锁在项目目录内，避免装到全局 site-packages。激活之后，pip 与 python 都指向这个环境；退出用 deactivate。依赖清单写成 requirements.txt，一条一条固定版本，别人复现时不用猜。

二、类型与可变性

Python 的类型挂在对象上，变量只是名字。给一个名字重新赋值，只是让它指向另一个对象，不会改变原先那个对象。这条规则决定了“传参是传引用”还是“传值”这类问题的答案：传的是引用，但不可变对象看起来像值。

a = [1, 2, 3]
b = a          # b 与 a 指向同一个列表
b.append(4)    # a 也变成 [1, 2, 3, 4]
c = a[:]       # 浅拷贝：新列表，元素还是原来那些对象

x = 256
y = 256
print(x is y)  # 小整数有缓存，这里为 True，但不能依赖

== 比较值，is 比较身份。判断“是不是同一个对象”用 is，判断“内容是否相等”用 ==；把 is 用在数字、字符串上，结果取决于缓存，写进代码就是隐患。唯一约定成俗的用法是 x is None。

不可变类型包括 int、float、str、tuple、frozenset，它们可以作字典键或集合元素；list、dict、set 不可哈希，放进去会直接抛 TypeError。

三、序列与循环

items = ["a", "b", "c", "d"]
items[1:3]        # ['b', 'c']，区间左闭右开
items[::-1]       # 反转
for i, v in enumerate(items):
    print(i, v)
for k, v in {"x": 1}.items():
    pass
for a, b in zip([1, 2, 3], "xy"):
    pass          # 长度取较短的一方

range(n) 不产生列表，只在迭代时逐个给值。切片越界不报错，返回能拿到的那一段；单下标越界才抛 IndexError。这一点在写边界判断时很有用：s[-3:] 对短串也安全。

列表头部的删除是 $O(n)$：del items[0] 和 items.pop(0) 都要整体前移。需要频繁两端操作时用 collections.deque；只需要尾部操作时 append 与 pop() 都是均摊 $O(1)$。

四、函数

默认参数只在函数定义时求值一次，所以可变默认值会被所有调用共享，这是 Python 最经典的一个坑。约定做法是把默认值写成 None，进函数后再创建。

def add(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

def f(a, b=2, *args, **kwargs):
    print(a, b, args, kwargs)

f(1)                 # 1 2 () {}
f(1, 3, 4, k=5)      # 1 3 (4,) {'k': 5}

名字查找的顺序是 local → enclosing → global → builtin。函数内给全局变量赋值需要 global 声明，但更稳的做法是把状态放进参数或类里。闭包捕获的是变量本身：外层变量被重新绑定后，内层看到的是新值，不是定义时的快照；要固定值就用默认参数把值绑进去。

五、异常与文件

try:
    n = int(text)
except ValueError as e:
    print("不是整数:", e)
else:
    print("解析结果", n)
finally:
    pass

with open("data.txt", encoding="utf-8") as f:
    for line in f:
        line = line.rstrip("\n")

不要写裸 except:，它会连 KeyboardInterrupt 一起吞掉；需要兜底时至少写 except Exception 并把异常重新抛出或记录。else 分支在没异常时执行，适合把“成功之后的处理”和“可能抛错的语句”分开。

with 保证退出时关闭文件，即使中途抛异常。文本文件一定显式写 encoding：Windows 默认编码与 Linux 不同，读同一个文件可能一边正常一边乱码。路径拼接用 pathlib.Path，比手拼字符串和斜杠可移植。

六、类与模块

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

p = Point(1, 2)
print(p)           # Point(1, 2)

__init__ 负责初始化，创建对象的是 __new__，多数场景不用关心。__repr__ 给人看的调试表示，__str__ 给最终输出，两者都实现时 print 走 __str__。

模块就是文件，包就是带 __init__.py 的目录（3.3 之后命名空间包可以省略该文件）。脚本作为程序入口时用 if __name__ == "__main__": 保护，避免被 import 时把主流程跑一遍。from m import * 会覆盖同名符号，正式代码里不要用。

七、易错点

  • 可变默认参数：def f(x, acc=[]) 里的列表会跨调用共享。
  • 用 is 比较数字或字符串，结果依赖缓存。
  • 循环中边遍历边删除元素，会跳过元素；改成遍历副本或用推导式重建。
  • / 永远返回浮点，// 是向下取整，负数方向与直觉相反：-7 // 2 == -4。
  • 循环里用 s += str(x) 拼字符串是 $O(n^2)$，改成列表收集后 "".join()。
  • 函数名与变量名遮住内置函数（list = [...]），后续调用会失败。
