动态规划（三）：斜率优化与凸包的维护

2026-11-20 · 编号 00000006

转移式里一旦出现决策变量与阶段变量的乘积，枚举决策就等于在一条直线上找最小值。这类项在分段代价、运输费用、平方误差的题里非常常见，把它整理成一次函数之后，枚举就变成了凸包上的切线查询。

一、把转移式整理成一次函数

取一个具体形式：

$$f_i=\min_{j<i}\left(f_j+(S_i-S_j)^2\right)+c_i$$

其中 $S_i$ 单调不减。展开平方项，把与 $i$ 无关的部分和不含 $j$ 的部分分开：

$$f_i=S_i^2+c_i+\min_{j<i}\left(f_j+S_j^2-2S_iS_j\right)$$

括号里是关于 $S_i$ 的一次函数。令 $k=2S_i$、$x_j=S_j$、$y_j=f_j+S_j^2$，要算的就是 $\min_j\,(y_j-kx_j)$，几何上是以斜率 $k$ 的直线去切点集 $\{(x_j,y_j)\}$，切点给出最优决策。

若点集的下凸壳已知，最小值一定出现在切点，且切点随斜率单调移动。这就是斜率优化这个名字的来历。注意此处的 $k$ 与 $x_j$ 都是整数，比较全程可以用叉积和乘法完成，不需要浮点。

二、按数据结构选维护方式

横坐标查询斜率做法复杂度
单调单调单调队列，队头弹出均摊 $O(1)$ 每次
单调无序凸壳上二分切点$O(\log n)$ 每次
无序无序按 $x$ 排序后 CDQ 分治$O(n\log n)$ 总
无序且需要在线任意李超线段树$O(n\log^2 n)$ 总

表里的"查询斜率单调"一般由 $S_i$ 单调给出。$S_i$ 是前缀和时几乎总是单调，这也是斜率优化最常见的入口。

三、单调队列的实现

维护下凸壳。插入点时，若最后三点构成右转或共线，说明中间那个点永远不会成为切点，弹出。查询时，若队首的下一个点比队首更优，弹出队首。

struct Point { long long x, y; };

long long cross(const Point &o, const Point &a, const Point &b) {
    return (long long)((__int128)(a.x - o.x) * (b.y - o.y)
                     - (__int128)(a.y - o.y) * (b.x - o.x));
}

std::deque<Point> hull;

void add(Point p) {
    while (hull.size() >= 2 &&
           cross(hull[hull.size() - 2], hull.back(), p) <= 0)
        hull.pop_back();
    hull.push_back(p);
}

long long query(long long k) {
    while (hull.size() >= 2) {
        __int128 lhs = (__int128)(hull[1].y - hull[0].y);
        __int128 rhs = (__int128)k * (hull[1].x - hull[0].x);
        if (lhs <= rhs) hull.pop_front();
        else break;
    }
    return hull.front().y - (__int128)k * hull.front().x;
}

query 返回的是 $y-kx$，量级约为 $|y|+|k||x|$。$k$ 与 $x$ 都在 $10^9$ 附近时，绝对值仍在 64 位有符号数之内，再大就要把返回类型改成 __int128，不能指望隐式转换。上面的弹队首条件对应斜率 $k$ 单调递增、求最小值；$k$ 单调递减时不等号方向相反，或者改从队尾查询。

四、精度与相等点

全整数时一律用叉积和乘法比较，不要用 double 算斜率。$10^{18}$ 量级的差积在 64 位里会溢出，上面用 __int128 是必要的，代价只是常数大一点。

横坐标相同的点只保留 $y$ 最小的那个。否则叉积为 $0$，凸壳判据会把有效点误弹掉；查询斜率恰好等于两点连线斜率时，取等号的方向也要统一，避免决策点在两段之间来回跳。

若代价本身是实数，用 long double，叉积判据加一个相对量级的 eps。此时凸包维护和查询都可能因为误差丢掉正确切点，写完必须对拍，eps 不要凭感觉取。

五、几种常见变形

  • 决策代价是线性函数 $w(j,i)=a_jS_i+b_j$：直接套用上面的整理，$x_j$ 与 $y_j$ 换一下即可。
  • 距离取绝对值：拆成 $S_i>S_j$ 与 $S_i<S_j$ 两种情况，分别维护上凸壳与下凸壳，查询时各取一次。
  • 决策点被限制在窗口 $[i-L,i-1]$ 内：在单调队列基础上加时间戳，队头过期就弹；若窗口内还要二分，则改用可删的凸壳或线段树维护。
  • 树上斜率优化：每个节点维护一个凸包，自底向上启发式合并或可并堆合并，查询在合并之前完成，总复杂度 $O(n\log^2 n)$。

六、两道标准题

玩具装箱：$f_i=\min_{j<i}\left(f_j+(i-j-1+s_i-s_j-L)^2\right)$，$s$ 为长度前缀和。展开后 $k=2(i+s_i)$ 关于 $i$ 单调，$x_j=j+s_j$ 也单调，单调队列即可，复杂度 $O(n)$。这道题的下标偏移量容易写错，建议先用暴力对拍。

土地购买：先把矩形按长度排序，把被完全包含的矩形去掉，剩下的宽度单调递减，代价化为 $长_i\times 宽_j$ 的形式，再套斜率优化。去重这一步不做，方程里的代价函数就不满足单调性，优化会失效。

仓库建设、任务安排、打印文章都属于同一套路：把代价拆开，把含 $i$ 的项提出去，剩下的部分对 $j$ 是线性的。
