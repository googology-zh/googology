JavaScript 入门：类型、函数与异步

2026-11-21 · 编号 00000025

JavaScript 的入门门槛低，坑也集中。本文只讲四件事：变量与类型、函数与 this、数组对象、异步。DOM 与事件放在最后，作为浏览器侧的最小可用部分。示例在浏览器控制台与 Node 里都能跑，涉及平台差异的地方单独注明。

一、两个运行环境

node app.js
node -e "console.log(process.version)"
npm init -y

浏览器与 Node 共享的只有语言本身和事件循环。DOM、window、localStorage 只存在于浏览器；文件系统、进程、网络底层只存在于 Node。写代码时先确认这段逻辑跑在哪一边，否则会碰到 document is not defined 这类错误。

浏览器里普通 <script> 是全局作用域、非严格模式；加 type="module" 或写 "use strict" 就进入严格模式，隐式全局变量、给只读属性赋值都会直接报错。新代码一律按严格模式写。

二、变量与类型

let n = 10;
const s = "text";

typeof null          // "object"，历史遗留
null == undefined    // true
null === undefined   // false
Number("12px")       // NaN
NaN === NaN          // false
0.1 + 0.2            // 0.30000000000000004

let 有块级作用域，const 只固定绑定，不冻结对象内容：const o = {}; o.x = 1 完全合法。var 是函数作用域且会提升，现在只在兼容老代码时见到。

== 会做类型转换，null == undefined、"0" == 0、"" == false 都为真；统一用 ===。判断 NaN 用 Number.isNaN，因为 NaN !== NaN。浮点误差没法消除，金额用整数分或者字符串转十进制库。

三、函数与 this

function add(a, b) { return a + b; }
const inc = a => a + 1;

const obj = {
  v: 1,
  get() { return this.v; }
};

const detached = obj.get;
detached();               // this 丢失
obj.get.call({ v: 2 });   // 2

箭头函数没有自己的 this 与 arguments，它取定义位置外层的值；普通函数的 this 由调用方式决定：obj.get() 绑定到 obj，单独拿出来调用就绑定到 undefined（严格模式）。

call、apply、bind 可以显式指定 this，bind 返回一个新函数且不可再改。回调里要保留外层对象，用箭头函数最省事；需要动态 this 时才用普通函数。

四、对象与数组

const { a, b = 0 } = obj;
const arr = [...xs, 9];

const total = xs.map(x => x * 2)
                .filter(x => x > 3)
                .reduce((sum, x) => sum + x, 0);

[10, 2, 1].sort();                  // 1, 10, 2，按字符串比
[10, 2, 1].sort((x, y) => x - y);   // 1, 2, 10

Object.keys(obj);
Object.entries(obj);

map、filter、slice、concat 返回新数组，不改原数组；sort、reverse、splice、push 就地修改。sort 默认把所有元素转字符串再比较，数字排序必须传比较函数，这是最常见的错误之一。

for...in 遍历可枚举的键，会带上原型链上的属性；for...of 遍历可迭代对象的值，数组、字符串、Map、Set 都支持。数组的 length 可写：赋值变小会截断，赋值变大会留出空位，空位与 undefined 在遍历时表现不同。

五、异步

async function load(url) {
  const res = await fetch(url);
  if (!res.ok) throw new Error("HTTP " + res.status);
  return res.json();
}

load("/api/list")
  .then(list => console.log(list.length))
  .catch(err => console.error(err));

async 函数总是返回 Promise；await 只能在 async 函数或模块顶层使用。抛出的异常会变成 rejected Promise，所以要么在调用处 catch，要么在 try/catch 里 await。

多个互不依赖的请求应当并行：Promise.all([a(), b()])；写成两行 await 会串行执行，总耗时相加。发起后忘记 await 的 Promise 出错时不会中断当前流程，只会产生一个未处理拒绝。

六、DOM 与事件

const btn = document.querySelector("#go");

btn.addEventListener("click", event => {
  event.preventDefault();
  console.log(event.target, event.currentTarget);
});

事件从 window 向下捕获到目标，再向上冒泡。addEventListener 默认在冒泡阶段触发，第三个参数传 true 改到捕获阶段。target 是实际被点的元素，currentTarget 是挂监听的那个，两者在冒泡时不同。

列表、表格这类会动态增删的容器，把监听挂在父元素上做事件委托，既省监听器，也不怕节点被替换。同步插入大量节点时先用 DocumentFragment 攒起来再一次性挂上，减少重排。

七、易错点

  • 用 == 比较，被隐式转换骗过一次就再也不敢用。
  • const 对象被修改，误以为它是不可变的。
  • 数字排序没传比较函数，sort() 按字符串排。
  • 回调里的 this 丢失，或者箭头函数想用 arguments。
  • for...in 遍历数组下标，拿到的是字符串键。
  • 异步函数里忘了 await，Promise 对象被当成结果用。
