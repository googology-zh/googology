动态规划专题：WQS 二分与拉格朗日松弛

2026-11-21 · 编号 0000000e

题目要求"恰好选 $k$ 个"，而状态里带上"选了几个"会让复杂度多一维。若最优值与 $k$ 的关系是离散凹的，可以给每个选取加一个罚金 $\lambda$，把约束去掉，再二分 $\lambda$ 反解出 $k$。这套做法在 OI 里叫 WQS 二分或 Aliens trick，本质是拉格朗日松弛。

一、把约束塞进目标函数

设 $f(k)$ 为恰好选 $k$ 个时的最优值。定义

$$g(\lambda)=\max_{k}\left(f(k)-\lambda k\right)$$

$g$ 是 $f$ 的支撑函数：给每个选取定价 $\lambda$，不再限制个数，让算法自己决定选多少。对固定的 $\lambda$，$g(\lambda)$ 对应的那个 $k$（记作 $k(\lambda)$）就是最优决策的个数。$\lambda$ 越大，选取越贵，$k(\lambda)$ 越小；这正是能二分的原因。

$k(\lambda)$ 单调的充分条件是 $f$ 离散凹：差分 $\Delta_k=f(k)-f(k-1)$ 随 $k$ 递减。此时每个 $k$ 都是某条斜率 $\lambda$ 的支撑点，二分找到使 $k(\lambda)\le k$ 的最小 $\lambda$，就能把 $f(k)$ 还原为

$$f(k)=g(\lambda)+\lambda k$$

几何上，$f$ 的点集位于其上凸包的下方；$g(\lambda)$ 是斜率为 $\lambda$ 的支撑线与纵轴的交点。若 $f$ 不凹，中间的点不在凸包上，无论怎么二分都取不到它。

二、二分的对象是罚金，不是答案

二分的区间要覆盖所有可能的斜率：取 $C$ 大于任意单个决策的收益绝对值之和，令 $\lambda\in[-C,C]$。$\lambda=-C$ 时选取几乎免费，$k(\lambda)$ 取到最大；$\lambda=C$ 时 $k(\lambda)$ 取到最小。于是"$k(\lambda)\le k$"在区间右端为真、左端为假（只要 $k$ 可行），二分有解。

比较两个候选解时不能只看值。值与个数都要参与比较：值大者优；值相同时，统一取个数少者（或统一取多者，但不能两种混用）。这套比较让 $k(\lambda)$ 成为"值相同情形下的最小个数"，它关于 $\lambda$ 单调不增，二分才稳定。若只在值相等时随便取，$k(\lambda)$ 会在平台上来回跳，二分收敛到一个错误的 $\lambda$，最后的 $g(\lambda)+\lambda k$ 也随之出错。

三、check 怎么写：以最大 $k$ 段和为例

给定序列 $a_1,\dots,a_n$，选恰好 $k$ 个互不相交的非空连续段，使元素和最大。带罚金的版本不限制段数，用两个状态即可：f0 表示当前位置不在段内，f1 表示在段内。每开一个新段扣 $\lambda$。

typedef long long ll;
const ll NEG = -(ll)4e18;

struct P { ll val; int cnt; };

bool better(const P &a, const P &b) {      // 值大者优，值相同取段数少者
    if (a.val != b.val) return a.val > b.val;
    return a.cnt < b.cnt;
}
P bestP(P a, P b) { return better(a, b) ? a : b; }

P check(ll lam) {
    P f0{0, 0}, f1{NEG, 0};
    for (ll x : a) {
        P n0 = bestP(f0, f1);                        // 在这一格之前收尾
        P n1 = bestP(P{f1.val + x, f1.cnt},          // 延续上一段
                     P{n0.val + x - lam, n0.cnt + 1});// 开新段，扣罚金
        f0 = n0; f1 = n1;
    }
    return bestP(f0, f1);
}

ll solve(int k) {
    ll C = 1;
    for (ll x : a) C += llabs(x);
    ll lo = -C, hi = C;
    while (lo < hi) {
        ll mid = lo + (hi - lo) / 2;
        if (check(mid).cnt <= k) hi = mid;
        else lo = mid + 1;
    }
    P r = check(lo);
    return r.val + lo * (ll)k;
}

n0 必须先算，再用它去开新段。写成"用上一轮的 f0 开新段"会漏掉"上一段恰好在上一格结束、新段从这一格开始"的情形，也就是相邻两段的情形。这个错误在小数据上表现为答案偏小，且只在 $k$ 较大时出现，不容易一眼看出来。

check 是 $O(n)$，二分 $O(\log C)$ 次，总复杂度 $O(n\log C)$，与 $k$ 无关。原来的 $O(nk)$ 或 $O(nk\log n)$ 在这套做法前没有优势。

四、成立条件必须验证

WQS 二分的唯一前提是 $f$ 离散凹。这个性质不会从题面里读出来，写之前应当验证：对小 $n$ 枚举所有 $k$，算出 $f(k)$，检查差分是否递减。随机若干组数据，若出现 $\Delta_{k+1}>\Delta_k$，这套做法就不成立，得回到带个数维度的 DP。

常见满足凹性的情形：选 $k$ 个互不相交区间、选 $k$ 条不相交路径、树上选 $k$ 个两两距离受限的点。常见不满足的情形：要求恰好 $k$ 个且每个的收益独立但可正可负、带背包体积约束——后者的 $f(k)$ 一般不是凹的，硬套会得到偏小的答案。

五、几种变形

  • 最小化问题：把收益取负，或把罚金改成奖励，二者等价；注意比较方向与二分条件一起翻转。
  • 答案是实数：罚金也取实数，二分改成固定次数（如 60 次），最后用 g + λk 还原并注意误差放大。
  • 要求"至少 $k$ 个"：若 $f$ 单调不减，直接取 $k(\lambda)\ge k$ 的一侧，答案仍在同一条支撑线上。
  • 树上选点：check 换成树上 DP，其余不变；此时 check 的复杂度决定总复杂度，常配换根或重链剖分。

最后一句提醒：二分结束后要再调用一次 check(lo)，不能复用循环里最后一次的结果。二分退出时 lo 与最后一次 mid 未必相同，用错那一次的 cnt 去还原，答案会差一个 $\lambda$。
