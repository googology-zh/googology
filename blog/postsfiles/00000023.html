Perl 入门：标量、上下文与正则

2026-11-21 · 编号 00000023

Perl 的语法宽容度很高，同一件事常有五六种写法；这在脚本里是优点，在长代码里是风险。入门部分按现代用法整理：严格模式、标量、数组与哈希、上下文、控制流、子程序、正则。示例都用 use strict 与 use warnings。

一、运行方式与严格模式

#!/usr/bin/env perl
use strict;
use warnings;

my $name = "world";
print "hello, $name\n";

use strict 要求变量必须用 my 声明，拼错变量名会直接报错而不是静默变成新变量；use warnings 把可疑写法变成告警，例如把字符串当数字用。两行都写，是写 Perl 的最低要求。

命令行运行 perl script.pl；perl -c script.pl 只做语法检查并加载模块，不执行主流程。-e 直接执行一段代码，-n、-p 把脚本当成对每一行的循环，读文件时很省事。

二、标量、字符串与数字

my $n = 10;
my $s = 'literal $n';        # 单引号不插值
my $t = "interpolated $n";   # 双引号插值

print $n + 1, "\n";
print "abc" eq "abc" ? "same\n" : "diff\n";
print "ab" x 3, "\n";        # ababab

数值比较用 ==、!=、<，字符串比较用 eq、ne、lt、gt。混用不会报错："abc" == 0 成立，因为非数字字符串在数值上下文里被转成 0，比较结果永远为真。这是 Perl 里最难查的一类 bug，严格模式也拦不住，只能靠习惯。

字符串连接用 .，重复用 x。双引号里的 @array 会被插值成所有元素，想输出字面美元符号就写 \$，或者干脆用单引号。

三、数组与哈希

my @list = (1, 2, 3);
push @list, 4;
my $last = pop @list;

my %h = (a => 1, b => 2);
$h{c} = 3;
for my $k (keys %h) {
    print "$k => $h{$k}\n";
}

my @slice = @list[0, 2];
print scalar @list, "\n";     # 元素个数

$#list 是最后一个下标，不是长度。哈希的键在内部一律是字符串，$h{1} 与 $h{"1"} 指向同一项。keys 返回的顺序不保证，需要稳定输出时自己 sort。

each 适合边遍历边处理，但遍历中途增删键会让迭代器失效。exists $h{k} 判断键存在，defined $h{k} 判断值是否已定义——两者不能互相替代，因为键存在而值为 undef 是合法状态。

四、上下文：标量上下文与列表上下文

my @a = (1, 2, 3);
my $count = @a;      # 标量上下文，得到 3
my @copy = @a;      # 列表上下文，得到三个元素

sub size {
    return wantarray ? scalar(@_) : \@_;
}

同一个表达式放在不同位置会给出不同结果，这是 Perl 最容易被误读的地方。print @a 输出三个元素，print scalar @a 输出 3。函数返回值同样受调用位置影响：wantarray 在列表上下文返回真、标量上下文返回假、无返回值上下文返回 undef。

五、控制流与循环

if ($x > 0) { print "positive\n" }
print "ok\n" if $ok;

while (my $line = <STDIN>) {
    chomp $line;
    last if $line eq "quit";
    print "> $line\n";
}

for my $i (0 .. 9) { print $i }
for (1 .. 3) {
    next if $_ == 2;
    print "loop $_\n";
}

foreach 与 for 是同义词，循环变量缺省时用 $_。last 跳出、next 进下一轮、redo 重跑当前一轮且不重新求值条件。0 .. 9 在列表上下文是范围，在标量上下文是翻转开关，写 for (0 .. 9) 才是想要的。

六、子程序

sub sum {
    my @nums = @_;
    my $total = 0;
    $total += $_ for @nums;
    return $total;
}

print sum(1, 2, 3), "\n";
print sum(), "\n";

参数全在 @_ 里，它是一个别名数组：$_[0] = 5 会直接改掉调用方的变量。稳妥写法是先 my @args = @_ 复制一份，再用 shift 或下标取。返回值在列表上下文返回列表，所以 return (1, 2) 与 return 1, 2 都需要留意调用方要几个值。

七、正则表达式入门

my $s = "abc 123 def";
if ($s =~ m/(\d+)/) {
    print "found $1\n";
}

$s =~ s/\d+/456/;
my @nums = $s =~ m/(\w+)/g;
print "@nums\n";

=~ 绑定匹配，!~ 取反。省略 m 也可以，/pattern/ 就是匹配。/g 在列表上下文返回所有捕获，在标量上下文变成逐次迭代，同一个修饰符两种语义。

贪婪匹配 .* 会尽量吃掉字符，最小匹配写 .*?。捕获组在匹配成功后才有效，下一次匹配会覆盖 $1 到 $9；要跨语句使用就先存进变量。

八、易错点

  • 字符串与数字比较混用，"abc" == 0 为真。
  • 忘记 my，变量落进全局包，跨函数串值。
  • print @list 与 print scalar @list 输出不同，调试时先想清楚上下文。
  • 哈希键带空格或特殊字符时必须加引号，写成 $h{some key} 会告警并得到错误结果。
  • 循环里改 @_ 或直接改循环列表元素，影响调用方数据。
  • 正则跨行匹配要加 /s，多行锚点要加 /m，两者含义不同。
